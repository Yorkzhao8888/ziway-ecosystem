## 一、部署架构

```
                    ┌──────────────────────────────┐
                    │          Kong 网关            │
                    └─────────────┬────────────────┘
                                  │
        ┌────────────┬────────────┼────────────┬────────────┐
        ▼            ▼            ▼            ▼            ▼
   ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐
   │  Mall   │ │  Shop   │ │  Lab    │ │ Market  │ │  Case  │
   │  (APP)  │ │  (APP)  │ │  (APP)  │ │  (APP)  │ │  (APP)  │

        │            │            │            │            │

   ┌──────────────────────────────────────────────────────────┐
```

---

## 二、P0 运行进程

| 进程 | 数量 | 说明 |
|:----:|:----:|:----|
| **OAS** | 1 | 单 Go 进程，含 OS 编排层 + MS 模块 |
| **Kong 网关** | 1 | API 网关 + 直通 OS 路由 |
| **PostgreSQL** | 1 | 共享数据库，按租户独立 Schema |
| **Redis** | 1 | L1/L2 缓存 |
| **Kafka** | 1 | XBUS 事件总线 |

**P0 后端进程：3 个**（OAS + Kong + Kafka，Redis/PG 为基础设施）

## 三、物理拆分触发条件（满足任一即拆分）

| # | 条件 | 说明 |
|:--:|:----:|:----|
| 1 | 独立数据库需求 | 如医疗 HIPAA、金融 PCI DSS |
| 2 | 独立部署频率 | 某 OS 需独立发布周期 |
| 3 | 独立资源配额 | 某 MS 需独占算力（如 AI 推理）|
| 4 | 独立安全域 | 如支付、风控需物理隔离 |
