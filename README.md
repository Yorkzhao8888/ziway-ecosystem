## 五·五、一致性守卫（A1.4 新增）

为杜绝铁律随时间回退，A1.4 引入 **CI 自动化一致性守卫**，作为全量文档集的"守门人"：

| 组件 | 路径 | 作用 |
|:---|:---|:---|
| 守卫脚本 | `scripts/check_consistency.py` | 扫描全量文档，校验 8 条铁律；支持 `--fix`（自动修复）、`--coverage`（场景覆盖）、`--json`（CI 消费）|
| CI 工作流 | `.github/workflows/consistency.yml` | PR/push 自动运行，发现 `error` 级违规即阻断合并 |
| 铁律文档 | `07_场景范例/00_一致性约束.md` | 8 条铁律的人类可读权威定义（R1~R8）|

### 快速使用

```bash
# 本地运行完整守卫（含场景覆盖检查），违规即 EXIT=1
python3 scripts/check_consistency.py --coverage

# 机器可读报告（CI 消费）
python3 scripts/check_consistency.py --coverage --json

# 自动修复可机械处理的违规（R1/R2/R3）
python3 scripts/check_consistency.py --fix
```

### 8 条铁律速览

| # | 铁律 | 等级 |
|:-:|:---|:---:|
| R1 | 层命名：`X-OS` / `X-MS` / `OAS`（禁用 BOS/MBS/OSA/BS）| error |
| R2 | 价值链命名：TM（禁用 PM）| error |

| R6 | 单一事实源：通用表（iam.*）不重复定义 | warning |
| R7 | 事件契约：幂等键 = eventType + eventId，72h 超时，DLQ | warning |

### 忽略机制（避免误伤）

- **行级忽略**：确需保留旧名作对照时，行尾加 `<!-- guard:ignore 原因 -->`
- **迁移语境**：含"旧/原为/曾用/原名/迁移/→/历史/deprecated/legacy/LOCKED/A1."等词的行自动跳过
- **元规范文档**：以 `00_` 开头的索引/契约/约束文件（如 `00_一致性约束.md`、`00_OpenAPI.yaml`）自动跳过，因其本身是规则定义
