# 行业适配器模板

> 定义"第二个行业怎么复制"——将创世纪流程（见 `05_方法论/A_创世纪流程.md`）工程化。

---

## 一、行业适配五步法

| 步骤 | 名称 | 说明 |
|:----:|:----:|:----|
| A | **立项绑定** | 行业 + OU 绑定到租户 |
| B | **术语映射** | 通用术语 → 行业术语 |
| C | **角色裁剪** | 从 12U 中选择子集 + 权限 |
| D | **神案子类型** | 四类神案的行业化配置 |
| E | **变量化重构** | 基于模板生成代码 |

---

## 二、五表清单

| 表 | 名称 | 内容 |
|:--:|:----:|:----|
| **T1** | 立项表 | 行业名、OU 绑定、租户 ID |
| **T2** | 术语映射表 | 通用术语 → 行业术语 |
| **T3** | 角色裁剪表 | 12U 子集 + 每角色权限 |
| **T4** | 神案子类型表 | VCASE/FCASE/ICASE/XCASE 子类型 |
| **T5** | 价值链配置表 | TM/DM/EM/CM 映射 |

---

## 四、一致性约束

适配过程必须遵守：

- **五层架构**（U / APP / OS / MS / OAS，其中 U+APP 为前台，OS+MS 为中台，OAS 为后台）
- **四根身份**（OU/HU/EU/GU，CU 为派生）
- **价值链四段**（TM→DM→EM→CM）
- **四类神案**（VCASE/FCASE/ICASE/XCASE，VCASE 权威源=VMS）
- **OAS 单项目**（三逻辑平面，多租户数据隔离）
